# Data

`sample_messages.csv` is **synthetic** (generated by `scripts/make_sample_data.py`).
It exists only so the code runs end to end. Do not report its metrics as results.

## Real datasets to use (download manually, check each license)

| Dataset | Use |
|---|---|
| UCI SMS Spam Collection | Baseline SMS spam vs legitimate |
| A smishing-focused SMS dataset (search "SMS phishing dataset smishing" on Mendeley Data / Kaggle) | Smishing-specific labels |
| PhishTank (verified phishing URLs) | URL-based phishing detection |
| Kaggle phishing email datasets | Email phishing |

## Format expected by `src/train.py`

A CSV with two columns:

```
text,label
"Your KYC has expired, update now ...",1
"Are we still meeting at 6 pm?",0
```

`label`: 1 = phishing/smishing, 0 = legitimate.

When using a real dataset, train with `--dedupe-normalized` so near-duplicate
messages (same text, different link or number) cannot leak between train and test:

```
python src/train.py --data data/your_dataset.csv --dedupe-normalized
```
